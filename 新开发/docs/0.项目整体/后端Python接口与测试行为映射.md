# Python 后端接口契约与副作用映射

> 状态：现行验收基线；已逐路由核对输入字段、校验、响应、错误和持久化/队列边界。
> 适用日期：2026-11-17
> 不要据此实施：否

本文记录后端运行入口 `apps/backend-python/baoxian_api/app.py` 及其业务服务。下表的“副作用”写明请求本身的读写边界；后台 Worker 后续副作用另列于后文。

## 公共契约

- 除 `GET /health` 外，所有路由（包括未登记路径）要求 `Authorization: Bearer <INTERNAL_API_TOKEN>`。缺失或错误返回 `401 {code: "unauthorized", message}`；认证在路由分发前执行。
- FastAPI/Pydantic 参数错误统一为 `400 {code: "validation_error", message: "请求参数无效", details: [{path, message}]}`。业务错误的专用状态码见路由表。未捕获的数据库、Redis、MinIO 异常保持 HTTP 500，不伪装成业务错误码。
- `not_found` 为统一 404 code；以下使用 `400 code` 等简写表示 HTTP 状态及 JSON `code`。所有数据库时间序列化为 UTC ISO 字符串（毫秒、`Z`）。
- `DATABASE_URL` 是产品库；`CRAWL_DATABASE_URL` 是任务、设置、调度、快照、失败和待确认运行库；队列固定沿用 BullMQ/Redis，默认队列名 `crawl`；文件与 HTML 快照对象沿用 MinIO。接口不改 schema。

响应字段缩写按以下完整目录理解：产品行含 `id,companyId,companyName,name,identityGroup,sameNameCount,salesStatus,salesStatusRaw,saleDateRaw,previousSalesStatusRaw,statusFetchedAt,sourceUrl,officialProductUrl,categoryCode,categoryName,officialProductCode,filingNumber,confirmedName,confirmedSalesStatus,correctionNote,confirmedAt,confirmedBy,integrationStatus,integrationStatusReason,integrationLastTaskId,integrationStatusUpdatedAt`；产品详情另含 `associationRecords[{associationRecordId,salesStatus,salesStatusRaw,saleDateRaw,statusFetchedAt,sourceUrl,categoryCode,categoryName,officialProductCode,filingNumber}]`、`materials[{type,label,status}]`、当前 `sources[]` 和历史 `history[]`（来源项含 `id,documentId,type,sourceUrl,downloadUrl,snapshotKey,fetchedAt,linkStatus,mimeType,size`）。任务行含 `id,type,status,scope,config,reportedTotal,readCount,uniqueCount,parentTaskId,createdAt,updatedAt,startedAt,finishedAt`；单元含 `id,taskId,unitKey,page,state,cursor,attempts,lastError,updatedAt`。任务响应中的内部 `_` 前缀 scope 字段会剔除。快照项字段为 `id,documentId,taskId,snapshotKind,sourceUrl,downloadUrl,snapshotKey,pageTitle,supportingText,fetchedAt`。待确认行含 `id,type,status,taskId,payload,resolution,resolvedProductId,resolvedBy,createdAt,updatedAt,resolvedAt`；计划行含 `id,categoryCode,categoryName,everyMinutes,enabled,createdAt,updatedAt`；失败行含 `id,taskId,companyId,productId,type,title,downloadUrl,sourcePageUrl,reason,message,createdAt,companyName,productName`。列表接口返回 `{items}` 或表中标出的分页/报告外层字段。

## 尚未覆盖的验收边界

- 接口的输入/响应字段、显式校验、业务错误码和数据库/队列副作用已逐项记录，并有路由测试或服务集成测试支撑。
- 当前没有启动桌面审查服务；本轮通过隔离测试链路验证，不向默认 `crawl` 队列投递/消费任务。真实浏览器页面行为仍待用户审查。
- 友邦/国寿的全量目录、所有资料类型和历史文件仍不由这组受控链路测试证明；其他公司专用适配器未注册，按用户要求不纳入本阶段改造或验收。
- TS 数据库迁移入口仍是现行脚本；本轮未改变数据库路线或 schema，也没有执行迁移。
