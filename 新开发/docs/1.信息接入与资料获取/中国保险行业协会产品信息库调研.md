## 初次静态调研结论

协会确有全国人身保险产品查询库；公开前端代码具有按条件查询、产品结果分页及详情入口，不是只能输入已知产品名称。当前代码要求至少选择一级产品类别，产品名称和公司名称均可为空。因此“按类别、无产品关键词发现产品”有静态证据；“全空条件查询”“已经实测可遍历全部产品”“完整公司目录可直接导出”均未得到证实。

本次成功读取官方首页及其公开 JavaScript，但浏览器扩展未连接，未完成真实 UI 查询、翻页或详情验证，也未调用业务查询接口、提交验证码、获取产品原件。分页机制存在不代表实际结果无截断，更不代表平台覆盖全部历史产品、每份附件均齐全。

前端结果区含未经允许禁止下载和数据提取的明确提示。用户已于 2026-11-07 确认具备使用许可，可批量抓取，该提示作为来源事实保留，不再构成接入前置。不要把“已获授权”等同于全库覆盖或接口可用性已经验证；也不要把该站默认设为可直接批量复制的全国主库。

## 发现与遍历途径逐项核查

下表均来自上述[查询页脚本](https://tiaokuan.iachina.cn/static/js/chunk-67efcfcb.b8d662bf.js)，除明确写明外均为静态代码核验。

| 问题 | 发现 | 能得出的结论及边界 |
| --- | --- | --- |
| 是否必须知道产品名称 | `prodname` 默认空字符串；产品名输入标记“模糊”，无必填规则 | 代码允许不填产品名称；实际查询返回尚未验证 |
| 是否可全空查询 | `formRules.cplbone` 配置 `required: true`，提示“不能为空”；查询先执行表单 `validate` | 正常 UI 全空条件不通过，不能称“空查询即可全部产品” |
| 能否按公司查询 | `inscomname` 是“公司名称（模糊）”文本输入，非公司下拉选择 | 可与类别组合查询的静态证据；公司单独查询仍受类别必填限制 |
| 是否存在完整公司列表 | 查询表单没有公司枚举；另有“保险公司客户服务电话”按钮跳转 `/phone` | 电话页的公司数量与完整性未验证；不能据按钮认定已取得公司目录 |
| 无关键词如何发现 | 类别字段为 `cplbone/cplbtow/cplbthree/cplbfour`，最终选中的类别写入 `prodtypecode`；可空产品名、公司名 | 依类别查询、逐页浏览是候选路径。父级类别是否包含全部子级、分类是否互斥完整均未验证 |
| 销售状态条件 | `salestatus` 默认空，选择项由 `getcpxszt()` 加载 | 有销售状态筛选；空值是否包含所有状态、具体枚举值未实测，不猜编码 |
| 分页是否存在 | `pageNum=1`、`pageSize=10`；分页 UI 支持 10/20/30/40；含 total、prev、pager、next、sizes、jumper | 确有分页设计；翻页和更改每页数均调用 `getList()`；未验证后台总数、页数上限或重复记录情况 |
| 查询返回形态 | 返回 `data` 经前端转换后 JSON 解析，读取 `records`、`total` | 有结果总数设计；未取得实际响应，不提供解码或采集脚本 |
| 自动加载全库 | `created()` 执行 `getData()` 加载筛选字典；结果表初始为空，点击查询执行 `getList()` | 首屏不是自动展示全库结果 |
| 全库下载或导出 | 查询页组件未发现全量导出按钮；公开官方公告未提供数据包或开放 API 文档 | “本次未发现”不等于证明不存在，需向协会确认 |

## 销售状态与原件机制

官方 2023 年[升级公告](https://www.iachina.cn/art/2023/8/17/art_22_107111.html)说明可查产品销售状态、条款文字编码等信息，并新增在售个人产品费率表、个人一年期以上产品现金价值表、说明书等资料。公告对资料种类有适用范围，不能解释为所有停售产品都有这些文件。

[查询页代码](https://tiaokuan.iachina.cn/static/js/chunk-67efcfcb.b8d662bf.js)中的结果列为公司名称 `inscomname`、产品名称 `prodname`、销售时间 `saledate`、销售状态 `salestatus` 及“详细信息”。销售状态属于源站显式字段，后续若获准接入应保留原始值和获取时间；不以搜索缺失推断停售。

点击“详细信息”先调用 `/captcha`，展示“验证您的身份”对话框，再将验证码相关字段和 `termsno` 交由 `/prodtermsinfo/selectDetail` 校验。成功后打开 `/#/center?data=<termsno>`。本次仅阅读逻辑，没有获取、识别、提交或绕过验证码，也没有凭猜测的 `termsno` 访问详情。

[实际跳转的 `/center` 组件](https://tiaokuan.iachina.cn/static/js/chunk-eb49ba4e.1d2bb73f.js)显示以下机制：

- 详情调用 `/salemaintaapply/getHtmlData`，参数为 `termsno`；返回数据中存在 `prodVo.base`、`termsVo.base`、`termsVo.file`、`termsVo.phone`、`termsVo.tip` 等结构。
- `termsVo.file` 每项显示其 `name`，操作文字为“预览PDF”；点击后将该项 `type/value` 放入本地临时状态并打开 `/view`。不是在该组件中直接暴露普通 PDF 下载链接。
- 条款内容使用 `pdf/getPdfPage` 请求逐页预览；显示为 `data:image/png;base64,...`，并按 `totalPage` 翻页。因此看见“PDF”字样不等于拿到了可下载 PDF 原件。
- 文件字段和内部预览路径只是代码结构证据。本次未确认任意具体文件存在、可预览、可下载或是否存在另一个合规原件下载入口。

主脚本还包含通用下载 helper，但没有证据显示查询页把它作为产品原件下载功能使用，不能据此推导全库导出能力。另一个 `/detail` 路由脚本包含示例地址及占位字段，不能用它替代查询实际打开的 `/center` 路由作实现依据。

## 覆盖口径与使用提示

2023 年[官方公告](https://www.iachina.cn/art/2023/8/17/art_22_107111.html)将范围表述为 2009 年新《保险法》实施后人身保险公司报备或审批的、境内在售及停售相关产品，并给出截至 2023-07-31 的历史统计。该表述不自动证明 2026 年当前数据实时完整，也不涵盖所有 2009 年以前产品，更不能扩展为所有财产保险公司的全部产品。报告不把历史数量作为当前验收数字。

[查询页脚本](https://tiaokuan.iachina.cn/static/js/chunk-67efcfcb.b8d662bf.js)的结果区域在 `tableList.length` 为真时渲染提示：“本库信息仅供浏览，未经允许禁止下载、数据提取或用于其他商业目的”。这是此次读取的现行前端声明；本次没有加载出真实结果页，故属于明确的静态证据，不能冒称 UI 实测截图。用户已确认具备使用许可并可批量抓取（2026-11-07），该声明作为源站使用提示保留；批量提取仍按任务范围执行。
