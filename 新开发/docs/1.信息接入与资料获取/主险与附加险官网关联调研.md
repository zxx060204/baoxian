# 主险与附加险官网关联调研

> 状态：调研记录（非已批准规格）
> 调研日期：2026-11-12
> 不要据此实施：是；涉及存储、规则或采集路线的决定须另行确认。

## 问题与结论

本次检索公开的一手资料，重点看人身险公司官网是否以独立目录公开主险—附加险完整适用关系，以及不解析附加险正文能否建立关联。样本是定向检索而非全国官网普查；网页可访问性、内容、销售状态会变化。本次以公开检索和页面读取为主，不等于已经完成本地采集器端到端验证。阳光页面直接读取仅返回 JavaScript 壳，平安公司文章直接读取超时；两项来自检索结果或其他读取路径，需在真实浏览器复核。富德页面正文可见但响应中混有 404 内容，不能据此确认页面稳定可用。

- **有公开的具体组合关系，但未发现可据此认定为全国通用或公司全量的公开适用关系矩阵。** 珠江、阳光、同方全球、平安和富德生命官网的计划介绍明确列出主附险，足以证明各自所描述计划的组合事实。不能由这些页面推断该附加险只适用于该主险，或所有可搭配关系均已公开。
- 官网产品目录可能列出产品及主附险身份，但这与列出产品对的适用关系是不同的信息。分栏、同页出现、名称相似或同一下载链接均不能单独证明任意两个产品可搭配。财险目录样本用于说明目录结构差异，不作为人身险覆盖的证据。
- 不解析附加险正文，可以从保险公司明确列名的产品计划、销售页面及产品说明书提取**有来源限定的正向组合事实**；实际保单可证明某笔合同中曾有的搭配，但需合法权限且不能证明通用可售规则。以上均不能单独替代完整、实时的搭配规则。对于未明确列名或范围不清的关系保留未知；未发现不等于不适用。
- 关系与资料归属是不同问题。组合页明确列出多个产品，并不自动证明该页每一个 PDF 都属于每个产品；须分别检查文件标题、链接上下文及页面表述，未明确时保留候选。名称、版本和产品身份不能可靠匹配时保留原文并待确认。

## 人身险官网：明确列名的案例

1. **珠江人寿，鸿运年年。** [产品详情](https://www.prlife.com.cn/page/product/person/detail/product_detail_002.shtml)原文称“由主险……以及附加险……构成”。主险为“珠江鸿运年年年金保险”，附加险为“珠江附加智赢两全保险（万能型）”。这是该产品组合明确命名的两个成员，可支持该计划内的一条关系；页面未声称列全两个产品的其他搭配，也未提供适用起止时间或证明当前在售。

   本地库核查补充：主险 #14313，附加险同名记录 #16781、#17879、#19544 的来源记录 ID 不同；页面仅以名称列示，无法仅凭名称确定对应哪条记录，也不能自动归并。此本地记录由本次协作中独立核查提供，产品身份与版本仍待核实。
2. **珠江人寿，安惠意外。** [销售详情](https://www.prlife.com.cn/page/shop/lineproduct/personproduct/detail/product_detail_0143.shtml)产品信息分别列明主险“珠江安惠意外伤害保险”，及可选附加险“珠江附加意外伤害医疗保险（A款）”“珠江附加意外住院津贴医疗保险（A款）”，页面标注“可选”。支持该销售页面中两条可选关系，页面另标销售区域广东省、北京市；不能扩展为不限区域、不限时间的承保规则。
3. **阳光人寿，爱随行E。** [保障计划页面](https://ikb.yg95510.com/insurance_market/Accompanying_E)明确“主险为：阳光人寿爱随行E款两全保险”，并列出附加险“阳光人寿附加爱随行E款意外伤害医疗保险”；页面说明可单独购买主险，也列有其他附加险。可直接支持该计划中明确的主附组合，其他附加险应保留页面自身表述及上下文；页面明确介绍简略，以保险合同条款为准。
4. **同方全球人寿，新康健一生（多倍保）。** [公司新闻](https://cmsweb.aegonthtf.com/aboutUs/gsxw/gsxw/2559.shtml)将“同方全球「新康健一生」（多倍保）重大疾病保险”列为主险，并将“同方全球附加（D款）投保人豁免保费重大疾病保险”和“同方全球附加「御欣」医疗保险”列为“两个可选的附加险”。可证明该报道所述计划中的两条可选组合；新闻并非实时投保系统，也未证明全部其他适配主险。
5. **平安人寿，爱妻宝。** [公司文章](https://life.pingan.com/next/news/detail?id=A79E121D933378D9E0531D3C210A2397)明确主险“平安女性公共交通意外伤害保险”，列出“平安附加男性公共交通意外伤害保险”“平安附加一年女性特定疾病保险”“平安附加一年男性特定恶性肿瘤疾病保险”，并说“附加险可选”。此为当时文章所述计划的三条组合事实；不能证明当前销售、个人投保条件或排他性。
6. **富德生命人寿，福星高照。** [产品页面](https://www.sino-life.com/product/cpfl/grbx/397197.shtml)风险提示中称本计划由主合同“生命福星高照终身寿险（分红型）”和附加合同“生命附加福相随提前给付重大疾病保险”组成。可证明该计划的组合事实；历史名称、版本和当前状态仍须另查。

以上均为保险公司自己公开的页面，关系依据是明确文字，不依赖解析附加险正文。页面列出“计划组成”只证明所描述计划存在该组合；即使可选，也不意味任何保单在任意条件下可新增。

## 目录、保单和规则的边界

- [珠江人寿个人产品展示目录](https://www.prlife.com.cn/page/product/person/product_person_001.shtml)直接在“康逸人生”摘要中写明主险“珠江康逸人生两全保险（分红型）”与附加险“珠江附加重大疾病保险”。它是产品展示列表中存在组合信息的例子，但页面本身未声明是全公司主附险适用关系清单，且其他列表项的摘要并不都列出成员。
- 对比样本：[三星财产保险产品条款目录](https://www.samsunganycar.com/cn/gkxxpl/jbxxpl/jycpjtk/index.shtml)列有“主附险类型”、产品名称及注册编号；[国泰财产保险产品基本信息](https://www.cathay-ins.com.cn/information?id=195)分“在售主险”“在售附加险”等栏目。两者证明存在按类型分类的公开目录，但所查页面没有一个明确的成对适用矩阵；不能据此推断人身险公司均使用同一结构，亦不能排除这些公司其他页面有进一步信息。
- [平安新增附险办理规则](https://pingan.com/official/ques-22200-27104994)称须符合“新增当时的投保规则（含险种搭配关系）”，又指出不同渠道和停售附险等限制，页面自身提示以最新公告及正式约定为准。该规则针对保全新增附险，说明这一场景的搭配受时间、渠道和保单条件影响，不能泛化为所有承保；这不是公开的产品对清单。
- [太平洋保险保单查询指南](https://service.cpic.com.cn/xljcms/fwzn/page1/bdcxzn/index.shtml)称保单查询包含主险名称及附加险信息。经授权的真实保单可说明具体合同中存在何种组合；指南本身不列出任何具体产品对，也不能外推所有产品适用范围。个人保单通常涉及敏感资料，不是可直接批量公开采集的目录。
- [汇丰银行代销清单](https://origin-www.hsbc.com.cn/content/dam/hsbc/cn/docs/transfers/sales-agency-product-info.pdf)由销售机构发布，说明附加险须与主险一起购买并符合投保规则；它是渠道产品清单，并非逐对搭配矩阵，不能将同一清单中的任意主附险配对。清单版本标注 20251214，动态地址可能被更新，须以实际下载版本为准。

## 监管及渠道资料的补充边界

[原银保监会关于规范短期健康保险业务的通知](https://www.nfra.gov.cn/chinese/OFFICE/PDF/958198.pdf)要求将短期健康险设计成附加险时告知消费者对应主险情况；其适用对象和销售场景有限，不能据此认定所有公司须公开全量搭配矩阵，亦不代表此处对现行效力完成了专项法律审查。

[汇丰银行托管的安联安康逸家+(III)产品组合文件](https://www.hsbc.com.cn/content/dam/hsbc/cn/docs/insurance/allianz-ankang-yijia-product-iii.pdf)明确列出两个主险和一款可选附加险，且对成人版组合注明全家保条件。它是渠道托管的 PDF 销售文件，需要读取说明书内容才能提取，并非官网网页或无需解析文档的独立证据。该例说明多主险组合不能不带条件地做笛卡尔积。

## 说明书和条款的补充证据

[汇丰人寿附加豁免保险费（2024）疾病保险产品说明书](https://www.hsbcinsurance.com.cn/content/dam/hsbc/insh/docs/products/2024/wpf/%E6%B1%87%E4%B8%B0%E9%99%84%E5%8A%A0%E8%B1%81%E5%85%8D%E4%BF%9D%E9%99%A9%E8%B4%B9%282024%29%E7%96%BE%E7%97%85%E4%BF%9D%E9%99%A9%E4%BA%A7%E5%93%81%E8%AF%B4%E6%98%8E%E4%B9%A6.pdf)描述可附加于公司提供的主合同及其附加险合同，但所引表述没有逐个命名主险；它是产品说明书中的一般范围线索，不能仅凭这一句话展开为公司全部主险的产品对。不同版本、其他条件及当时投保规则仍需核实。

对照 [太保附加两全其美两全保险条款](https://www.cpic.com.cn/upload/resources/file/2025/04/02/85993.pdf) 的合同订立段，仅说由主险合同投保人与公司订立，未在该段命名主险；不能由此认定条款全文一定没有限定，也不能推算具体配对。这说明即便选择进一步解析条款，也未必能得到完整矩阵。

## 对后续研究的建议（待确认）

优先按公司识别能直接命名双方的产品计划页、投保页面与产品说明书；保存精确来源、标题、获取时间、原文及计划、可选性、区域、版本等上下文。一个来源只支持其实际表述的正向事实；没有来源时保持未知，页面消失或历史销售状态变化不自动视为关系被否定。是否建立关联模型、人工确认流程或开展扩展采集，需结合现行 P1/P2 边界另行讨论和批准；本报告没有实施这些变更。
