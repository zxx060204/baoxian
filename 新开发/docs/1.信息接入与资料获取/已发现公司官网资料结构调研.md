## 范围与方法

依据产品库只读 API 清单快照（2026-11-11T15:53:21.628Z，即北京时间 23:53），103 家中已有官网字段的 94 家；本表覆盖全部 94 家，不把官网字段等同于有效官网。逐站 GET 原始登记地址，最多跟随重定向，超时 12 秒，记录最终 URL、HTTP 状态、首页可见的产品/披露链接；有匹配链接时选择一条再次 GET。请求按 8 个并发进行；这是入口普查，非完整产品、分页、PDF 下载与全量业务验证。列表按公司 ID 顺序。来源是每行链接所指公司站点及本地 API 快照；HTTP 状态只反映本机本次请求，200 也可能是空壳、招聘站或集团首页。仅有导航文案不能证明目录可遍历，也不能证明资料存在。入口选取受页面标记和脚本渲染影响，未取到链接不表示不存在。

原始结构化结果：库存快照（本机记录 ../../.runtime/site-research-inventory.json）、首页探测（本机记录 ../../.runtime/site-homepage-probe.json）、入口探测（本机记录 ../../.runtime/site-entry-probe.json）。请求时间均为 UTC，表中每行时间对应首页首次请求；入口请求发生在其后同一次调研中。

## 主要发现与可复用性

- 94 个首页请求中 85 个 HTTP 200、2 个 412、2 个 DNS 失败、3 个连接超时、1 个整体超时、1 个 TLS 旧式重协商失败；这是访问结果而非可采集率。瑞众与国民养老的 200 是招聘门户；天安地址缺少有效域名后缀；华夏 DNS 失败。
- [海港人寿](https://www.harbourlife.com.cn/channel/11145.html)和[恒大原站](https://www.evergrandelife.com.cn/channel/11075.html)首页导航均按条款、费率、现金价值、说明书分栏目，海港还列出恒大及中新大东方材料。两站相同栏目路径是**共享目录解析候选**，不能仅凭外观确认文件归属、主体承继或直接共享完整 adapter。
- [建信人寿产品基本信息](https://www.ccb-life.com.cn/html/6182/3131/index.html) HTML 可见四类资料名称和多条 PDF 链接；[汇丰基本信息](https://www.hsbcinsurance.com.cn/about-us/information-disclosure/basic-information/)含在售/停售目录及四类名称，网页可见说明书链接；[瑞泰条款页](https://www.ruitailife.com/onlineService/customerService/prosuctClause/)可见产品名称及条款 PDF 链接。这些是结构证据，不代表每项文件已下载或同一产品四类齐全。
- [交银人寿目录](https://www.bocommlife.com/110032/index.html)区分在售、2024 年及以后停售和此前停售；[泰康产品目录](https://www.taikanglife.com/publicinfonew/basicnew/pubproduct/commonprodinfonew/list_542_1.html)有历史范围说明。具体分页与文件仍需实测。[国联产品变更公告](https://eservice.guolian-life.com/FileUpload/upload/20240318104132199.pdf)说明同一产品旧条款停用、新条款启用，文件名相近不足以确认当前版本。
- [招商信诺披露页](https://www.cignacmb.com/xinxi/jibenxinxi/gaikuang.html)按在售/停售及资料类型分入口；[太平洋人寿目录样页](https://www.cpic.com.cn/xrsbx/gkxxpl/jbxx/gsgk/jydbxcpmljtk/tbcp/sx/index_21.shtml)显示产品名称及条款、费率、现金价值、说明书、停售日期和历史版本列。列表型可考虑共享链接、分页和来源记录组件，但不能凭业务字段相同判定 DOM、分页和归属规则相同。
- 富泽和君康披露导航均出现相同相对路径 `../baseInfoProduct/baseInfoProduct.html`，恒安标准人寿和恒安标准养老的路径结构相似，是两组**待验证候选**，需要分别核查真实响应、分页、实际文件和主体。
- 94 家的 `documentEntryUrl` 均为空，非专用路径从根地址进入；调研时有 81 家落入通用路径、13 家落入 10 条专用域名规则（只读统计脚本（本机记录 ../../.runtime/site-route-inventory.mjs））。这不是采集成功数。
- **共享解析器真实样本与版本风险**：只读读取[工银安盛产品目录](https://www.icbc-axa.com/public/public_base/public_base_3/publicIndex.jsp)，“工银安盛人寿鑫佑祥禄25年金保险（分红型）”同一行分别列有[启用条款](https://www.icbc-axa.com/attachmentDir/file/202606/3016131907in.pdf)与[停用条款](https://www.icbc-axa.com/attachmentDir/file/202509/091143368gw4.pdf)。同一行的现行与历史附件需分别标注版本状态。人保寿险首页产品“人保寿险旅行意外伤害保险”提取条款、说明、费率三个候选，支持两站**部分产品行解析**可复用；文件下载、后续分页及其他产品未验证。两次仅读取入口页，后续请求由测试人为停止，所得 pageFailures 不代表真实站点失败。
- [工银安盛产品页](https://www.icbc-axa.com/public/public_base/public_base_3/publicIndex.jsp)显示同一产品下拉选项；[平安人寿示例说明书](https://life.pingan.com/ilife-home/product/getPlanClausePdf?attachmentType=7&planCode=2631&versionNo=2631-1)使用参数化文件端点。二者不能简单归为相同 DOM 目录。

建议后续以公司主体及精确入口配置分发；把页面解析、分页、文件下载和快照作为可组合能力，逐公司用真实产品检验在售、停售、历史版本、分页、四类文件及归属，再决定是否共用 adapter。存在名称、版本或主体歧义时保留待确认。
