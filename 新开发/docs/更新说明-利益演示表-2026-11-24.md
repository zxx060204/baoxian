## 这次加了什么

新增一个**独立的利益演示表生成服务**（后端 API），根据数据库中已采集的保险条款、费率表、现金价值表，输入年龄、性别、保费等参数，生成按保单年度展开的利益演示表。

全部为新文件，**未改动任何现有代码**：

| 文件 | 作用 |
| --- | --- |
| `apps/backend-python/baoxian_api/benefit_illustration.py` | 计算核心：费率表/现金价值表解析 + 传统两全公式模板 + 服务层 |
| `apps/backend-python/baoxian_api/benefit_api.py` | 独立 HTTP 服务：`POST /api/benefit-illustrations` |
| `apps/backend-python/baoxian_api/benefit_serve.py` | 启动入口，默认 `127.0.0.1:3002` |
| `apps/backend-python/tests/test_benefit_illustration.py` | 15 项单元测试 |

## 计算逻辑（传统两全险，公式来自条款）

以「国民福寿双全A05款两全保险」为首个样例，公式取自其条款保险责任：

- **基本保额** = 费率表数值（每 1000 元年交保费对应基本保额）× 年交保费 ÷ 1000
- **退保金（现金价值）** = 现金价值表单位值 × 年交保费 ÷ 1000
- **身故保险金** = max（现金价值，累计已交保费 × 到达年龄比例系数）
  - 比例系数：0–17 岁 100%｜18–40 岁 160%｜41–60 岁 140%｜61 岁及以上 120%
  - 到达年龄 = 投保年龄 + 保单年度 − 1（条款原文定义）
- **满期保险金** = 基本保额（保险期间届满年度给付）
- 数值按保险公司演示惯例取整

## 数据从哪来

- 产品文档记录读 MySQL `document` 表（只读）；
- 费率表、现金价值表读 MinIO 中已保存的解析结果（layout JSON）；
- 特殊情况：A05 的现金价值表是 1672 页纯文字"全表"（无表格线，几何识表结果为 0 张表），服务自动回退为按文字行解析 PDF 原件。首次请求约 30 秒，之后走进程内缓存为毫秒级；
- **不写任何业务数据**。

## 怎么跑

```powershell
# 1. 启动依赖（Docker：MySQL 3307 / Redis / MinIO）
cd 新开发\infrastructure\docker
docker compose up -d

# 2. 单元测试（15 项，含与说明书演示表逐年对账）
cd 新开发\apps\backend-python
..\..\.venv-python\Scripts\python.exe -m unittest tests.test_benefit_illustration -v

# 3. 启动服务
..\..\.venv-python\Scripts\python.exe -m baoxian_api.benefit_serve

# 4. 请求演示（男 40 岁 / 3 年交 / 年交 1 万 / 保至 90 岁）
$headers = @{ "Authorization" = "Bearer dev-internal-token"; "Content-Type" = "application/json" }
$body = '{"productId":13,"age":40,"gender":"male","coveragePeriod":"to_90","paymentPeriod":"3","annualPremium":10000}'
Invoke-RestMethod -Uri http://127.0.0.1:3002/api/benefit-illustrations -Method Post -Headers $headers -Body $body | ConvertTo-Json -Depth 5
```

## 验证结果（可与产品说明书对照）

- 基本保额 **91088** 元，与条款举例一致；
- 前 8 个保单年度退保金：6650 / 15972 / 26653 / 27828 / 29055 / 30339 / 31680 / 32449，**与产品说明书利益演示表逐年一致**；
- 身故保险金第 1–3 年：16000 / 28000 / 42000，与说明书一致；
- 第 50 年（90 岁）满期金 91088；
- 分红型产品（B01）请求返回 422，明确提示模板待后续支持。

## 接口速查

`POST /api/benefit-illustrations`，鉴权为 `Authorization: Bearer <INTERNAL_API_TOKEN>`（见 `.env`）。

| 参数 | 取值 |
| --- | --- |
| `productId` | 产品 ID（A05=13，B01=14） |
| `age` | 投保年龄 0–75 |
| `gender` | `male` / `female` |
| `coveragePeriod` | `to_60` / `to_70` / `to_80` / `to_90` |
| `paymentPeriod` | `single`（趸交）/ `3` / `5` / `10` |
| `annualPremium` | 年交保费（趸交时为一次交保费） |

输出：基本保额 + 按保单年度的演示行（当年保费、累计保费、满期金、身故保险金、退保金）。

## 当前边界

- 仅支持传统两全保险（非分红）；分红型、年金、增额终身寿、万能等需后续按险种补充公式模板；
- 暂无前端页面，演示用 curl / Postman / PowerShell；
- A05 现金价值全表在请求时即时解析，大文件首次较慢，后续可考虑解析产物落 MinIO；
- 减额交清、保单贷款、自动垫交等条款权益未纳入演示。
